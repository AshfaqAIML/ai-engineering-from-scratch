# Learn Math for Machine Learning: 22 Free Lessons

Canonical page: https://aiengineeringfromscratch.com/phase/math-foundations

The intuition behind every AI algorithm, through code, not textbooks.

## Lessons in Phase 01: Math Foundations

01. [Linear Algebra Intuition](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F01-linear-algebra-intuition): Every AI model is just matrix math wearing a fancy hat. Implement vector and matrix operations (addition, dot product, matrix multiply) from scratch in Python. (Learn, Python, Julia, ~60 min)
02. [Vectors, Matrices & Operations](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F02-vectors-matrices-operations): Every neural network is just matrix multiplication with extra steps. Build a Matrix class with element-wise operations, matrix multiplication, transpose, determinant, and inverse. (Build, Python, Julia, ~60 min)
03. [Matrix Transformations](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F03-matrix-transformations): A matrix is a machine that reshapes space. Learn what it does to every point, and you understand the whole transformation. (Build, Python, Julia, ~75 min)
04. [Calculus for Machine Learning](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F04-calculus-for-ml): Derivatives tell you which way is downhill. That is all a neural network needs to learn. Language: Python Compute numerical and analytical derivatives for common ML functions (x^2, sigmoid,… (Learn, Python, ~60 min)
05. [Chain Rule & Automatic Differentiation](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F05-chain-rule-and-autodiff): The chain rule is the engine behind every neural network that learns. Language: Python Build a minimal autograd engine (Value class) that records operations and computes gradients via reverse-mode… (Build, Python, ~90 min)
06. [Probability and Distributions](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F06-probability-and-distributions): Probability is the language AI uses to express uncertainty. Language: Python Implement PMFs and PDFs from scratch for Bernoulli, categorical, Poisson, uniform, and normal distributions. (Learn, Python, ~75 min)
07. [Bayes' Theorem](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F07-bayes-theorem): Probability is about what you expect. Bayes' theorem is about what you learn. Language: Python Apply Bayes' theorem to compute posterior probabilities from priors, likelihoods, and evidence. (Build, Python, ~75 min)
08. [Optimization](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F08-optimization): Training a neural network is nothing more than finding the bottom of a valley. Language: Python Implement vanilla gradient descent, SGD with momentum, and Adam from scratch. (Build, Python, ~75 min)
09. [Information Theory](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F09-information-theory): Information theory measures surprise. Loss functions are built on it. Language: Python Compute entropy, cross-entropy, and KL divergence from scratch and explain their relationship. (Learn, Python, ~60 min)
10. [Dimensionality Reduction](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F10-dimensionality-reduction): High-dimensional data has structure. You find it by looking from the right angle. Language: Python Implement PCA from scratch: center data, compute the covariance matrix, eigendecompose, and project. (Build, Python, ~90 min)
11. [Singular Value Decomposition](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F11-singular-value-decomposition): SVD is the Swiss Army knife of linear algebra. Every matrix has one. Every data scientist needs one. Implement SVD via power iteration and explain the geometric meaning of U, Sigma, and V^T. (Build, Python, Julia, ~120 min)
12. [Tensor Operations](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F12-tensor-operations): Tensors are the common language between data and deep learning. Every image, every sentence, every gradient flows through them. (Build, Python, ~90 min)
13. [Numerical Stability](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F13-numerical-stability): Floating point is a leaky abstraction. It will bite you during training, and you will not see it coming. Language: Python Implement numerically stable softmax and log-sum-exp using the… (Build, Python, ~120 min)
14. [Norms and Distances](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F14-norms-and-distances): Your distance function defines what "similar" means. Choose wrong and everything downstream breaks. Language: Python Implement L1, L2, cosine, Mahalanobis, Jaccard, and edit distance functions from… (Build, Python, ~90 min)
15. [Statistics for Machine Learning](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F15-statistics-for-ml): Statistics is how you know if your model actually works or just got lucky. Language: Python Compute descriptive statistics, Pearson/Spearman correlation, and covariance matrices from scratch. (Build, Python, ~120 min)
16. [Sampling Methods](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F16-sampling-methods): Sampling is how AI explores the space of possibilities. Language: Python Implement inverse CDF, rejection, and importance sampling from scratch using only uniform random numbers. (Build, Python, ~120 min)
17. [Linear Systems](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F17-linear-systems): Solving Ax = b is the oldest problem in mathematics that still runs your neural network. Language: Python Solve Ax = b using Gaussian elimination with partial pivoting and back substitution. (Build, Python, ~120 min)
18. [Convex Optimization](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F18-convex-optimization): Convex problems have one valley. Neural networks have millions. Knowing the difference matters. Language: Python Test whether a function is convex using the definition, second derivative, and… (Build, Python, ~90 min)
19. [Complex Numbers for AI](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F19-complex-numbers): The square root of -1 is not imaginary. It is the key to rotations, frequencies, and half of signal processing. Language: Python Perform complex arithmetic (add, multiply, divide, conjugate) in both… (Learn, Python, ~60 min)
20. [The Fourier Transform](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F20-fourier-transform): Every signal is a sum of sine waves. The Fourier transform tells you which ones. Language: Python Implement the DFT from scratch and verify it against the O(N log N) Cooley-Tukey FFT. (Build, Python, ~90 min)
21. [Graph Theory for Machine Learning](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F21-graph-theory): Graphs are the data structure of relationships. If your data has connections, you need graph theory. Language: Python Build a graph class with adjacency matrix/list representations and implement BFS… (Build, Python, ~90 min)
22. [Stochastic Processes](https://aiengineeringfromscratch.com/lesson?path=phases%2F01-math-foundations%2F22-stochastic-processes): Randomness with structure. The math behind random walks, Markov chains, and diffusion models. Language: Python Simulate 1D and 2D random walks and verify the sqrt(n) scaling of displacement. (Learn, Python, ~75 min)
