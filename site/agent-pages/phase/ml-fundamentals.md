# Learn Machine Learning from Scratch: 21 Free Lessons

Canonical page: https://aiengineeringfromscratch.com/phase/ml-fundamentals

Classical machine learning is still the backbone of most production AI.

## Lessons in Phase 02: ML Fundamentals

01. [What Is Machine Learning](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F01-what-is-machine-learning): Machine learning is teaching computers to find patterns in data instead of writing rules by hand. Explain the difference between supervised, unsupervised, and reinforcement learning and identify… (Learn, Python, ~45 min)
02. [Linear Regression](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F02-linear-regression): Linear regression draws the best straight line through your data. It is the "hello world" of machine learning. Derive the gradient descent update rules for mean squared error and implement linear… (Build, Python, ~90 min)
03. [Logistic Regression](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F03-logistic-regression): Logistic regression bends a straight line into an S-curve to answer yes-or-no questions with probabilities. Implement logistic regression from scratch using the sigmoid function and binary… (Build, Python, ~90 min)
04. [Decision Trees and Random Forests](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F04-decision-trees): A decision tree is just a flowchart. But a forest of them is one of the most powerful tools in ML. Language: Python Implement Gini impurity, entropy, and information gain calculations to find… (Build, Python, ~90 min)
05. [Support Vector Machines](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F05-support-vector-machines): Find the widest street between two classes. That is the entire idea. Language: Python Implement a linear SVM from scratch using hinge loss and gradient descent on the primal formulation. (Build, Python, ~90 min)
06. [K-Nearest Neighbors and Distances](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F06-knn-and-distances): Store everything. Predict by looking at your neighbors. The simplest algorithm that actually works. Language: Python Implement KNN classification and regression from scratch with configurable K and… (Build, Python, ~90 min)
07. [Unsupervised Learning](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F07-unsupervised-learning): No labels, no teacher. The algorithm finds structure on its own. Implement K-Means, DBSCAN, and Gaussian Mixture Models from scratch and compare their clustering behavior. (Build, Python, ~90 min)
08. [Feature Engineering & Selection](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F08-feature-engineering): A good feature is worth a thousand data points. Implement numerical transforms (standardization, min-max scaling, log transform, binning) and explain when each is appropriate. (Build, Python, ~90 min)
09. [Model Evaluation](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F09-model-evaluation): A model is only as good as the way you measure it. Implement K-fold and stratified K-fold cross-validation from scratch and explain why stratification matters for imbalanced data. (Build, Python, ~90 min)
10. [Bias-Variance Tradeoff](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F10-bias-variance): Every model error comes from one of three sources: bias, variance, or noise. You can only control the first two. Language: Python Derive the bias-variance decomposition of expected prediction error… (Learn, Python, ~75 min)
11. [Ensemble Methods](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F11-ensemble-methods): A group of weak learners, combined correctly, becomes a strong learner. This is not a metaphor. It is a theorem. Language: Python Implement AdaBoost and gradient boosting from scratch and explain… (Build, Python, ~120 min)
12. [Hyperparameter Tuning](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F12-hyperparameter-tuning): Hyperparameters are the knobs you turn before training starts. Turning them well is the difference between a mediocre model and a great one. (Build, Python, ~90 min)
13. [ML Pipelines](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F13-ml-pipelines): A model is not a product. A pipeline is. The pipeline is everything from raw data to deployed prediction, and every step must be reproducible. (Build, Python, ~120 min)
14. [Naive Bayes](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F14-naive-bayes): The "naive" assumption is wrong, and it works anyway. That's the beauty of it. Language: Python Implement Multinomial Naive Bayes from scratch with Laplace smoothing for text classification. (Build, Python, ~75 min)
15. [Time Series Fundamentals](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F15-time-series): Past performance does predict future results -- if you check for stationarity first. Language: Python Decompose a time series into trend, seasonality, and residual components and test for… (Build, Python, ~90 min)
16. [Anomaly Detection](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F16-anomaly-detection): Normal is easy to define. Abnormal is whatever doesn't fit. Language: Python Implement Z-score, IQR, and Isolation Forest anomaly detection methods from scratch. (Build, Python, ~75 min)
17. [Handling Imbalanced Data](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F17-imbalanced-data): When 99% of your data is "normal," accuracy is a lie. Language: Python Implement SMOTE from scratch and explain how synthetic oversampling differs from random duplication. (Build, Python, ~90 min)
18. [Feature Selection](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F18-feature-selection): More features is not better. The right features is better. Language: Python Implement filter methods (variance threshold, mutual information, chi-squared) and wrapper methods (RFE, forward… (Build, Python, ~75 min)
19. [ML System Design — From Problem to Deployed Model](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F19-ml-system-design): A model is one part of a system. The design decides what the model predicts, who acts on it, what it costs, and what happens when it fails. (Build, Python, ~110 min)
20. [Monitoring Models in Production — Data Drift and Concept Drift](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F20-model-monitoring-and-drift): A deployed model fails without an error message. It keeps returning scores while the world moves away from its training data, and only monitoring shows the gap. (Build, Python, ~110 min)
21. [Feature Stores and Training-Serving Skew](https://aiengineeringfromscratch.com/lesson?path=phases%2F02-ml-fundamentals%2F21-feature-stores-and-training-serving-skew): A feature has one definition and two readers. Training reads its history as of each label time, and serving reads its latest value. (Build, Python, ~100 min)
