# What are Repository Instructions?

Canonical page: https://aiengineeringfromscratch.com/glossary/repository-instructions
Category: AI-native development

Version-controlled guidance that tells coding agents how a repository is organized, which commands and conventions apply, what boundaries to respect, and how to verify work.

## Why do Repository Instructions matter?

It turns repeated tribal knowledge into local context that travels with the code and can vary by subproject.

## What is the common confusion about Repository Instructions?

Repository instructions complement source code and human documentation; they do not override the user's current request or guarantee that an agent follows them correctly.

## Repository Instructions in practice

Keep an `AGENTS.md` at the repository root, add narrower files for subdirectories, and include exact build, test, generated-file, security, and contribution rules.
