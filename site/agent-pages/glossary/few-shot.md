# What is Few-Shot?

Canonical page: https://aiengineeringfromscratch.com/glossary/few-shot
Category: Prompting & context

In-context learning that includes a small set of demonstrations before the target input so the model can infer the desired task, format, or decision boundary.

What people say: "Give the model a few examples in the prompt."

## Why does Few-Shot matter?

Example quality and coverage matter more than a universal example count. Poor or contradictory demonstrations can reduce reliability.
