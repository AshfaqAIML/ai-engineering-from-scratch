# What is System Prompt?

Canonical page: https://aiengineeringfromscratch.com/glossary/system-prompt
Category: Prompting & context

A provider-defined instruction message or configuration supplied by the application to establish behavior and constraints within that provider's instruction hierarchy.

What people say: "Developer-controlled instructions for a model interaction."

## Why does System Prompt matter?

System instructions can guide behavior, but they are not guaranteed to remain secret and should not be treated as a security boundary.

## What is the common confusion about System Prompt?

Priority rules, message roles, persistence, and visibility differ across APIs. Check the current provider contract.
