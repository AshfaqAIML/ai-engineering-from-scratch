# What is Skill Catalog?

Canonical page: https://aiengineeringfromscratch.com/glossary/skill-catalog
Category: Agents & tools

The compact model-visible inventory of eligible skills, usually containing routing metadata such as name, description, and an internal source identifier rather than every skill body.

## Why does Skill Catalog matter?

A catalog lets an agent discover relevant procedures without loading every installed package into the working context.

## What is the common confusion about Skill Catalog?

A catalog entry means the skill is discoverable. It does not mean the body is active or its tools are authorized.

## Skill Catalog in practice

Validate packages first, apply an explicit duplicate-name policy, measure the serialized catalog budget, and retain diagnostics for entries that were shortened, omitted, or shadowed.
