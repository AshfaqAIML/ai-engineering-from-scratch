# What is Feature?

Canonical page: https://aiengineeringfromscratch.com/glossary/feature
Category: Data & representations

An individual measurable property of the data. In classical ML, you engineer features by hand. In deep learning, the network learns features automatically from raw data.

What people say: "A column in a dataset."

## What is the common confusion about Feature?

A stored column can contain several useful features, and a learned representation can contain features with no simple human label.
