# What is Repository Map?

Canonical page: https://aiengineeringfromscratch.com/glossary/repository-map
Category: AI-native development

A compact, maintained description of a repository's important directories, ownership boundaries, entry points, build commands, tests, generated files, and local instructions.

## Why does Repository Map matter?

It helps a coding agent find the right evidence before loading large files or editing the wrong subsystem.

## What is the common confusion about Repository Map?

A raw file tree shows names. A repository map explains which paths matter and how they relate to a task.

## Repository Map in practice

Generate an index from the tree and manifests, then enrich it with authoritative notes about module boundaries and validation commands.
