# What is Postmortem?

Canonical page: https://aiengineeringfromscratch.com/glossary/postmortem
Category: Reliability & operations

A durable incident record that explains impact, detection, response, contributing conditions, recovery, and owned follow-up actions without assigning blame as a substitute for analysis.

## Why does Postmortem matter?

A resolved outage still has value as evidence. Capturing system conditions and decisions turns one event into improvements that reduce recurrence and response time.

## What is the common confusion about Postmortem?

A postmortem is not a meeting transcript or a search for one person's mistake. It should produce testable system improvements.

## Postmortem in practice

Build the timeline from traces and logs, distinguish triggering events from contributing conditions, assign dated actions, and review whether each action changed the relevant control.
