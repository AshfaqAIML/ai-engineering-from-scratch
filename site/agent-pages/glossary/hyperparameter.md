# What is Hyperparameter?

Canonical page: https://aiengineeringfromscratch.com/glossary/hyperparameter
Category: Math & training

A configuration choice that shapes model structure, optimization, data processing, or inference rather than being learned as an ordinary model parameter. Examples include learning rate, batch size, layer count, and decoding settings.

What people say: "A setting you tune."

## What is the common confusion about Hyperparameter?

Some hyperparameters are selected before training, while others can be changed during a schedule or at inference time.
