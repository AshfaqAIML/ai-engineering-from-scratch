# What is Parameter?

Canonical page: https://aiengineeringfromscratch.com/glossary/parameter
Category: Models & inference

A value learned during training, commonly a weight, bias, embedding element, or normalization parameter. Parameter count is one measure of model capacity, but it does not directly determine quality, memory, or serving cost.

What people say: "A number used to describe model size."

## What is the common confusion about Parameter?

Memory per parameter depends on numerical format, quantization metadata, sharding, optimizer state, activations, and runtime overhead.
