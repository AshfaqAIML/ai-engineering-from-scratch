# What is Cost per Successful Task?

Canonical page: https://aiengineeringfromscratch.com/glossary/cost-per-successful-task
Category: AI-native development

Total system cost divided by the number of tasks that satisfy a defined success criterion, including retries, failed runs, tool use, and evaluation overhead.

## Why does Cost per Successful Task matter?

A cheap model call can produce an expensive workflow if it fails often or requires repeated human correction.

## What is the common confusion about Cost per Successful Task?

Cost per token measures usage. Cost per successful task measures useful outcomes.

## Cost per Successful Task in practice

Measure provider charges and infrastructure cost across 100 repository tasks, then divide by the number whose patches pass tests and review.
