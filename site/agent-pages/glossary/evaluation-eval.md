# What is Evaluation (Eval)?

Canonical page: https://aiengineeringfromscratch.com/glossary/evaluation-eval
Category: Evaluation & safety
Also called: Eval

A defined process for measuring model or system behavior on representative tasks using explicit success criteria, data, scorers, and review procedures.

## Why does Evaluation (Eval) matter?

You cannot improve reliability if success is only a subjective impression from a few demos.

## What is the common confusion about Evaluation (Eval)?

A benchmark score is one evaluation result, not a complete account of production quality.

## Evaluation (Eval) in practice

Run the same customer-support scenarios before and after changing retrieval, score correctness and citation support, and inspect failures by category.
