# What is Least Privilege?

Canonical page: https://aiengineeringfromscratch.com/glossary/least-privilege
Category: Evaluation & safety

Giving a model, agent, tool, or user only the permissions required for the current task, for only as long as those permissions are needed.

## Why does Least Privilege matter?

Models can make mistakes or follow malicious instructions. Narrow permissions reduce the damage any one failure can cause.

## What is the common confusion about Least Privilege?

Authentication proves identity. Least privilege limits what that identity can do.

## Least Privilege in practice

Give a documentation agent read access to source files and write access to one branch, but no production credentials or merge permission.
