# What is Vector Database?

Canonical page: https://aiengineeringfromscratch.com/glossary/vector-database
Category: Retrieval & generation

A storage and indexing system that supports nearest-neighbor queries over vector representations, often with metadata filtering, persistence, and approximate indexes.

What people say: "A database optimized for vector similarity search."

## What is the common confusion about Vector Database?

A vector database stores and searches vectors. It does not create high-quality embeddings or guarantee relevant retrieval.
