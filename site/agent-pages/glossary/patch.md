# What is Patch?

Canonical page: https://aiengineeringfromscratch.com/glossary/patch
Category: AI-native development

A reviewable representation of changes to one or more files, usually expressed as additions and deletions against a known base revision.

## Why does Patch matter?

A patch gives people and agents a narrow artifact to inspect, test, apply, or reject without accepting an entire working directory.

## What is the common confusion about Patch?

A patch captures file changes, not the reasoning, test evidence, or approval needed to ship them.

## Patch in practice

Ask a coding agent to return a unified diff, then verify that it touches only allowed files and applies cleanly to the expected commit.
