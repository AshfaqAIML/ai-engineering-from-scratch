# What is Token?

Canonical page: https://aiengineeringfromscratch.com/glossary/token
Category: Data & representations

An integer identifier produced by a model-specific tokenizer from text, bytes, images, audio, or another input representation. A token can be a whole word, part of a word, punctuation, whitespace, a byte sequence, or a special control symbol.

What people say: "A word-sized piece of model input or output."

## What is the common confusion about Token?

Character-to-token ratios vary by language, content, and tokenizer, so count with the target model's tokenizer or provider tools.
