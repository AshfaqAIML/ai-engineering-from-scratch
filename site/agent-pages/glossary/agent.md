# What is Agent?

Canonical page: https://aiengineeringfromscratch.com/glossary/agent
Category: Agents & tools

A software system that lets a model select actions toward a goal, observe tool or environment results, and continue under an orchestration policy. An agent may use a loop, a state machine, a workflow engine, or human approvals. The model is one component, not the entire system.

What people say: "An autonomous model that thinks and acts alone."

## Why does Agent matter?

Reliability comes from the harness, tool contracts, state, permissions, and verification around the model.

## What is the common confusion about Agent?

Autonomy is a degree of delegated authority, not a required property of every agent.

## Agent in practice

A coding agent reads repository context, proposes a patch, runs tests in a sandbox, and stops for approval before deployment.
