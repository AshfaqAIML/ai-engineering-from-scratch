# What is Data Lineage?

Canonical page: https://aiengineeringfromscratch.com/glossary/data-lineage
Category: Security & governance

A record of how a data artifact was derived across sources, transformations, joins, filters, versions, and downstream uses.

## Why does Data Lineage matter?

When a source is corrected, revoked, or found unsafe, lineage identifies which datasets, embeddings, evaluations, and model artifacts may be affected.

## What is the common confusion about Data Lineage?

Data provenance explains origin and custody broadly. Lineage emphasizes the transformation path and dependencies between data artifacts.

## Data Lineage in practice

Give inputs and outputs stable identifiers, record each transformation and version, preserve parent-child relationships, and test whether an affected source can be traced to every derivative.
