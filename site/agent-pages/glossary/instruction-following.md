# What is Instruction Following?

Canonical page: https://aiengineeringfromscratch.com/glossary/instruction-following
Category: Prompting & context

A model capability to map natural-language directions and supplied context to behavior that satisfies the stated task and constraints.

## Why does Instruction Following matter?

Language generation can be fluent without obeying the user's requested operation, format, boundaries, or priorities.

## What is the common confusion about Instruction Following?

Instruction following is not factual correctness, alignment, or obedience to every string that looks like an instruction.

## Instruction Following in practice

Evaluate instruction adherence separately from answer quality using conflicting constraints, format requirements, irrelevant context, and refusal cases.
