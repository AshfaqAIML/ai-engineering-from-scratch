# What is Regression Test?

Canonical page: https://aiengineeringfromscratch.com/glossary/regression-test
Category: AI-native development

A repeatable check that protects behavior known to work, especially after code, prompt, model, retrieval, or tool changes.

## Why does Regression Test matter?

AI system changes can improve average quality while silently reintroducing a previously fixed failure.

## What is the common confusion about Regression Test?

A regression test guards a specific expected behavior. A broad benchmark estimates performance across a wider task distribution.

## Regression Test in practice

Turn a corrected prompt-injection incident into a permanent eval case that must pass before the next deployment.
