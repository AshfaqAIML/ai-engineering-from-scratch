# What is JAX?

Canonical page: https://aiengineeringfromscratch.com/glossary/jax
Category: Math & training

A Python library for transforming numerical functions with automatic differentiation, compilation, vectorization, and parallel execution across accelerators. Its transformations work best with explicit state and functional-style code.

What people say: "A NumPy-like system for accelerated machine learning."

## What is the common confusion about JAX?

JAX does not prohibit all stateful programming, but hidden mutation inside transformed functions can produce incorrect or unsupported behavior.
