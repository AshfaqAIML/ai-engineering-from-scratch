# What is Zero Trust?

Canonical page: https://aiengineeringfromscratch.com/glossary/zero-trust
Category: Security & governance

A security model that grants no implicit trust from network location or asset ownership and instead evaluates each access request against identity, device, resource, policy, and current context.

## Why does Zero Trust matter?

AI tools and agents span local files, cloud services, models, and external content, so a trusted internal network is too broad a basis for authority.

## What is the common confusion about Zero Trust?

Zero trust does not mean trusting nothing or blocking all automation. It means making trust decisions explicit, scoped, and continuously verifiable.

## Zero Trust in practice

Authenticate every actor and workload, authorize each resource action, issue short-lived credentials, segment access, and continuously record and reevaluate policy-relevant signals.
