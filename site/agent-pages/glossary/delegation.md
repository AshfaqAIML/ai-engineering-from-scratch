# What is Delegation?

Canonical page: https://aiengineeringfromscratch.com/glossary/delegation
Category: Agents & tools

Assigning a bounded subtask to another person or agent together with the needed context, authority, output contract, and return conditions.

## Why does Delegation matter?

Explicit delegation enables specialization and parallel work without losing ownership, scope, or the ability to integrate results.

## What is the common confusion about Delegation?

Sending a vague message to another agent is not reliable delegation. The receiver needs a scope contract and a defined handoff back.

## Delegation in practice

Give a reviewer agent the exact files, rubric, evidence, and deadline, then require it to return findings rather than silently modifying the primary artifact.
